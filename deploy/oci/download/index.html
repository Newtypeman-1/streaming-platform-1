나드리 데스크톱

브라우저 없이 나드리의 라이브와 녹화 방송을 볼 수 있는 앱입니다. 방송 목록을 보고, 고른 방송을 바로 재생합니다.

이 컴퓨터에 맞는 파일 Windows Windows 10·11, 64비트(x64) 설치 파일 받기 nadri-windows-x64-setup.exe
이 컴퓨터에 맞는 파일 macOS · Apple Silicon M1 이후 칩(arm64), macOS 11 이상 디스크 이미지 받기 nadri-macos-arm64.dmg
이 컴퓨터에 맞는 파일 macOS · Intel Intel 칩(x86_64), macOS 11 이상 디스크 이미지 받기 nadri-macos-x64.dmg

내 Mac의 칩은 Apple 메뉴 → 이 Mac에 관하여의 "칩" 또는 "프로세서" 항목에서 볼 수 있습니다. 파일 무결성은 SHA-256 체크섬으로 확인할 수 있습니다.

Windows에 설치하기

  1. nadri-windows-x64-setup.exe를 내려받아 실행합니다.
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다. 코드 서명을 하지 않은 앱이라 처음 한 번 나오는 경고입니다.
  3. 설치를 마치면 시작 메뉴의 Nadri로 실행합니다.
  4. 화면 표시에 쓰는 Microsoft Edge WebView2 런타임이 PC에 없으면 설치 중에 내려받아 함께 설치합니다(인터넷 연결 필요). Windows 11과 최근 업데이트한 Windows 10에는 이미 들어 있습니다.
  5. 그래도 앱 창이 비어 있으면 WebView2 런타임을 직접 설치합니다.
  6. 지울 때는 설정 → 앱 → 설치된 앱에서 Nadri를 제거합니다.

macOS에 설치하기

  1. 내 Mac에 맞는 .dmg를 내려받아 엽니다.
  2. 열린 창에서 Nadri를 응용 프로그램 폴더로 끌어 놓습니다.
  3. 응용 프로그램 폴더에서 Nadri를 엽니다.

"열 수 없습니다" 또는 "손상되었기 때문에 열 수 없습니다"가 뜰 때

Apple 개발자 인증서로 서명·공증하지 않은 앱이라, 인터넷에서 받은 파일을 처음 열 때 macOS가 막습니다. 아래 둘 중 하나로 한 번만 허용하면 됩니다.

  • 시스템 설정 → 개인정보 보호 및 보안 아래쪽의 "Nadri"이(가) 차단되었다는 안내에서 그래도 열기를 누릅니다.
  • 또는 터미널에서 다운로드 표시를 지운 뒤 다시 엽니다. 
    xattr -dr com.apple.quarantine /Applications/Nadri.app

사용하기

  • 왼쪽 목록에서 방송을 고르면 오른쪽에서 재생됩니다. LIVE는 지금 방송 중인 라이브, 녹화는 올라온 영상입니다.
  • 라이브는 소리를 끈 채로 시작합니다. 플레이어의 음소거를 해제하면 소리가 나옵니다.
  • 새 방송이 보이지 않으면 오른쪽 위 새로고침을 누릅니다.
  • 로그인, 댓글, 후원, 방송하기는 웹에서 할 수 있습니다.
